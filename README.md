# Robin Villier — Personal Site & Blog

Personal site and blog built with plain HTML/CSS/JS, hosted on GitHub Pages.
Serves as a resume/portfolio for IT support roles, with a blog for
troubleshooting write-ups and notes.

## Structure

- `index.html` — Home page
- `about.html` — About / Resume
- `blog/index.html` — Blog post listing
- `blog/posts/` — Individual blog post pages
- `css/` — Stylesheets
- `js/` — Scripts (shared nav/footer, blog listing, etc.)
- `assets/` — Images and other static files
